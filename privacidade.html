Política de Privacidade — Cry

Última atualização: 08/09/2026

Esta política explica como o Cry utiliza informações necessárias para fornecer suas funcionalidades no Discord.

1. Dados utilizados

O Cry poderá processar identificadores de usuários, servidores, canais, cargos e mensagens quando necessário para recursos como moderação, AutoMod, logs, segurança e configurações.

2. Finalidade

Os dados são utilizados exclusivamente para fornecer e manter as funcionalidades do Cry.

3. Compartilhamento

O Cry não vende dados pessoais dos usuários.

4. Armazenamento

Algumas configurações e informações necessárias ao funcionamento do bot poderão ser armazenadas enquanto forem necessárias para prestar o serviço.

5. Exclusão

Usuários ou administradores poderão solicitar informações sobre exclusão de dados entrando em contato com a equipe responsável pelo Cry.

6. Segurança

São adotadas medidas razoáveis para proteger as informações processadas pelo Cry.

7. Alterações

Esta política poderá ser atualizada conforme novos recursos forem adicionados ao Cry.
